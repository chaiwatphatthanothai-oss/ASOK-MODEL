# ASOK MODEL — ชุดเตรียมขึ้น GitHub Pages

สถานะ: ชุดเผยแพร่ตัวอย่าง ยังไม่ได้ทดสอบอ่าน/เขียนกับระบบจริงที่ใช้ Token
คงหน้าตาและข้อมูลตัวอย่างจากไฟล์ต้นฉบับไว้ทั้งหมด

## การเผยแพร่
1. สร้าง repository ชื่อ ASOK-MODEL ในบัญชี chaiwatphatthanothai-oss หรือเลือก repository ที่ต้องการ
2. อัปโหลดเฉพาะไฟล์ในชุดนี้ ห้ามอัปโหลดไฟล์สำรองหรือ Apps Script ที่มี Token จริง
3. ตั้ง Settings → Pages → Deploy from a branch → main → /(root)
4. เปิดเว็บที่ GitHub แจ้งหลัง deploy สำเร็จ

อ้างอิง: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## เชื่อมต่อ
URL Apps Script ที่ผู้ใช้ให้มาตั้งเป็นค่าเริ่มต้นแล้ว กรอก Token ในหน้าตั้งค่าแดชบอร์ดด้วยตนเอง
หากมี URL เก่าเก็บไว้ในเบราว์เซอร์ ให้แทนด้วย URL ล่าสุดก่อนทดสอบ
ทดสอบการเชื่อมต่อ แล้วตรวจข้อมูลในชีตก่อนสั่งส่งข้อมูลขึ้น Sheet
ยังไม่มีการส่งข้อมูลตัวอย่างเข้า Google Sheet หรือรีเซ็ตข้อมูลจริงจากงานรอบนี้

Google Sheet เป้าหมาย: https://docs.google.com/spreadsheets/d/1HuJEkYDn-N1NwXixwO4W8dT3NLQZ9DLaKWSDW_S8EsE/edit
ยังไม่ได้ยืนยันว่า deployment ผูกกับชีตนี้ ต้องทดสอบแบบมี Token ก่อน

## ขอบเขตปัจจุบัน
- กรอกผ่านแดชบอร์ด; อ่านกลับจากแท็บ _state ตาม Apps Script เดิม
- ยังไม่รองรับการแก้ตารางกิจกรรมใน Sheet แล้วอ่านกลับ
- ปุ่มรีเซ็ตยังคืนข้อมูลตัวอย่าง ไม่ใช่ตั้งทุกค่าเป็นศูนย์; ยังไม่ได้เปลี่ยนเพราะต้องตกลงว่าล้างเป้าหมาย/งบจัดสรรด้วยหรือไม่
- ยังไม่รองรับการแก้พร้อมกันหลายคนอย่างปลอดภัย (แต่ละเครื่องส่งข้อมูลทั้งชุด)
- รหัสเจ้าหน้าที่ใน HTML เป็นเพียงการล็อกหน้าจอ ไม่ใช่การยืนยันตัวตนฝั่งเซิร์ฟเวอร์; Token ของ Apps Script เป็นสิทธิ์อ่าน/เขียนจริง จึงไม่ฝัง Token ลง repository
- ยังไม่ควรถือว่าเป็นระบบ production จนผ่านทดสอบอ่าน/เขียนจริง การจัดการสิทธิ์ และการตั้งข้อมูลเริ่มต้น

## แก้ไขและตรวจแล้ว
- ไม่ส่งข้อมูลขึ้น Sheet เพียงเพราะเปิดหน้า เปลี่ยนธีม หรือวาดหน้าใหม่
- ไม่แจ้งบันทึกสำเร็จด้วยผล ping; อ่านกลับเปรียบเทียบข้อมูลที่ส่ง
- ตรวจรูปแบบ URL และจัดการ JSONP timeout/cleanup
- ทดสอบจำลอง 8 กรณีและตรวจ JavaScript syntax ผ่าน
- HTML/CSS และ defaultData เหมือนต้นฉบับทุกตัวอักษร
