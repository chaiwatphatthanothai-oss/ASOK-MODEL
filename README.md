# ASOK MODEL — เริ่มใช้งานจริง

เว็บไซต์: https://chaiwatphatthanothai-oss.github.io/ASOK-MODEL/

ตรวจเมื่อ 28 ต.ค. 2569: บันทึกข้อมูลเริ่มต้นว่างผ่านแดชบอร์ดและอ่านกลับตรงกัน ตรวจใน Google Sheet เป้าหมายว่ามีแท็บโครงการ กิจกรรม บันทึกรายครั้ง และ _state แล้ว งบประมาณ 0 และไม่มีกิจกรรม/ประวัติ

## เริ่มลงข้อมูล
1. ใช้เบราว์เซอร์ที่ตั้งค่า Token ไว้ รอให้แสดง “ซิงค์แล้ว”
2. เข้าสู่ระบบเจ้าหน้าที่ → ตั้งค่า: ตรวจชื่อโครงการ ช่วงเวลา และกรอกงบจัดสรร แล้วบันทึก
3. เพิ่มกิจกรรม กรอกเป้าหมาย/งบจัดสรร จากนั้นลงผลรายครั้ง
4. รอ “ซิงค์แล้ว” ก่อนปิดหน้า หากเกิดข้อผิดพลาด ให้ส่งออก JSON เก็บไว้ก่อน ไม่กดดึงข้อมูลทับงานที่ยังไม่บันทึก
5. ส่งออก JSON สำรองเป็นระยะ

## ขอบเขตที่ต้องปฏิบัติ
- ใช้เจ้าหน้าที่แก้ข้อมูลทีละคน/เครื่อง ไม่แก้พร้อมกันหลายแท็บ
- กรอกผ่านแดชบอร์ด การแก้ตารางรายงานใน Sheet ไม่ย้อนกลับเข้าแดชบอร์ด ระบบอ่านจาก _state
- Token เก็บเฉพาะเบราว์เซอร์นี้ เครื่องใหม่ต้องตั้งค่าเอง ห้ามใส่ Token ลง GitHub หรือส่งให้ผู้ชมทั่วไป
- รหัสเจ้าหน้าที่ล็อกหน้าจอเท่านั้น สิทธิ์อ่าน/เขียนจริงตรวจด้วย Token บน Apps Script ระบบนี้ยังไม่มีบัญชีผู้ใช้/สิทธิ์รายบุคคล
- ใช้สำหรับข้อมูลสรุปโครงการ ไม่ใช่ข้อมูลส่วนบุคคลอ่อนไหว
- ปุ่มรีเซ็ตจะล้างกิจกรรม/ประวัติและงบประมาณเป็นศูนย์ พร้อมซิงค์ไป Sheet เมื่อเชื่อมต่อ ให้สำรองก่อนใช้

รูปแบบ HTML/CSS คงเดิม ข้อมูลตัวอย่างถูกนำออกจากค่าเริ่มต้นแล้ว
